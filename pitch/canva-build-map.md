# Canva Build Map — turn the template into the Anchored institution deck

You have a good-looking Canva template, but it's built as an **investor deck** with
placeholder content. This maps each of your 12 institution slides onto the template's
layouts, so you know exactly what to keep, delete, repurpose, and duplicate.

**Full copy + speaker notes for every slide live in `deck-script.md`. This file only
tells you which template layout to use and what to change.**

Legend: **KEEP** = reuse layout, swap copy · **REPURPOSE** = same layout, new meaning ·
**DUPLICATE** = copy an existing slide to make a new one · **DELETE** = remove entirely.

---

## First: two hard rules

1. **Delete every fabricated element.** No fake team (Howard/Isabel/Greta), no invented
   metrics (45+ clients, 6,500 posts, 95% retention, $30K MRR), no fake milestones. You
   have none of these yet, and that's fine. Honesty is the brand.
2. **No market-sizing, no pricing, no funding ask** in the institution deck. Those belong
   in the *grant* deck (see bottom). An institution is deciding on a free pilot, not
   investing.
